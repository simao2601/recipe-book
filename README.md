# CookBook Hub

The platform to share and find recipes.

## Description

A web application where users share and discover cooking recipes. It solves the problem of recipes being scattered across many websites and notebooks by letting users save and search them in one place. It is designed for people who cook at home and want to find recipes based on the ingredients they already have. Users register, publish their own recipes with photos, and explore others' recipes through likes and comments.

## Tech stack

- **Language:** TypeScript
- **Frontend:** Next.js, ShadCN UI, TanStack Query
- **Backend:** NestJS, Prisma ORM (REST API)
- **Database:** PostgreSQL
- **Tools:** Docker, Docker Compose, JWT, bcrypt, multer, Swagger

## Functional requirements

1. A user can register and log in.
2. A user can create a recipe with a title, ingredients, steps and photos.
3. A user can edit their own recipes.
4. A user can delete their own recipes.
5. A user can view the list of recipes and the details of each one.
6. A user can search recipes by ingredient.
7. A user can like a recipe.
8. A user can comment on a recipe.
9. A user can filter recipes by category.
10. An admin can remove inappropriate recipes or comments.
